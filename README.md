# پنل فروش کانفیگ V2Ray / Xray

پنل لاراولی داکرایز‌شده برای **ساخت، مدیریت و فروش کانفیگ‌های V2Ray**.
کاربر پلن می‌خرد، پنل به‌صورت خودکار کانفیگ VLESS / VMess / Trojan می‌سازد،
لینک اشتراک (subscription) و QR تحویل می‌دهد و کاربر را روی سرورهای Xray شما اضافه می‌کند.

---

## امکانات

| بخش | توضیح |
|---|---|
| ساخت کانفیگ | VLESS، VMess، Trojan روی TCP / WS / gRPC / xHTTP با TLS یا **REALITY** |
| لینک اشتراک | خروجی base64 (v2rayNG/v2rayN)، خام، و **Clash Meta (YAML)** با تشخیص خودکار از روی User-Agent |
| هدرهای استاندارد | `Subscription-Userinfo`، `Profile-Title`، `Profile-Update-Interval` — کلاینت مصرف و انقضا را نشان می‌دهد |
| نود VPN داخلی | سرویس Xray در همین compose — با یک دستور راه می‌افتد، بدون SSH |
| چند سرور | هر سرور چند اینباند؛ هر پلن مجموعه‌ای از سرورها |
| همگام‌سازی نود | افزودن/حذف خودکار کاربر روی Xray؛ محلی یا از راه دور با SSH |
| خودترمیمی | اگر نودی ری‌استارت شود، کاربران خودکار بازنویسی می‌شوند |
| حساب‌داری ترافیک | خواندن `statsquery` هر ۵ دقیقه، قطع خودکار در اتمام حجم یا انقضا |
| فروش | پلن، سفارش، پرداخت کارت‌به‌کارت با تأیید مدیر، کیف پول، تمدید |
| پنل مدیریت | داشبورد، سرورها، اینباندها، پلن‌ها، سرویس‌ها، سفارش‌ها، کاربران |
| رابط کاربری | فارسی و RTL، ریسپانسیو |

## شروع سریع

```bash
cp .env.example .env
sed -i "s/^UID=.*/UID=$(id -u)/; s/^GID=.*/GID=$(id -g)/" .env

docker compose up -d --build
docker compose exec app php artisan db:seed --force
```

پنل روی <http://localhost:8080> بالا می‌آید.

برای اینکه **همین سرور خودش VPN هم باشد** (بدون نیاز به سرور دوم):

```bash
docker compose exec app php artisan panel:setup-local-node \
    --address=IP_عمومی_سرور --port=443
docker compose --profile vpn up -d xray
```

جزئیات و گزینهٔ سرور جدا: **[۰۳ — آماده‌سازی سرور Xray](docs/03-xray-node.md)**

| نقش | ایمیل | رمز |
|---|---|---|
| مدیر | `admin@panel.local` | `password` |

> **قبل از استفادهٔ واقعی حتماً رمز مدیر را عوض کنید.**

برای دیدن یک نمونهٔ کامل (سرور + سه اینباند + یک سرویس فعال):

```bash
docker compose exec app php artisan db:seed --class=DemoSeeder --force
```

## معماری

```
مرورگر ──► nginx ──► php-fpm (app) ──┬── MySQL      دادهٔ پنل
                                     └── Redis      کش، سشن، صف
                                          │
                  worker (queue + scheduler)
                                          │
              ┌───────────────────────────┴───────────────┐
              ▼ xray api (داخل شبکهٔ داکر)        SSH  ▼
        xray  ← نود محلی، همین سرور          سرور خارجی: Xray
        :443                                  (اختیاری، چند تا)
          ▲
          └── مشتری وصل می‌شود
```

| سرویس | نقش |
|---|---|
| `app` | PHP 8.4 + php-fpm (باینری Xray را هم به‌عنوان کلاینت API دارد) |
| `nginx` | وب‌سرور، پورت `8080` |
| `worker` | صف (`queue:work`) و زمان‌بند (`schedule:work`) با supervisor |
| `xray` | **نود VPN روی همین سرور** — با پروفایل `vpn` بالا می‌آید |
| `mysql` | MySQL 8.4 |
| `redis` | کش، سشن، صف |

سه حالت مدیریت نود (فیلد «روش مدیریت کاربران» روی هر سرور):

| حالت | یعنی |
|---|---|
| `محلی` | Xray در همین compose؛ پنل مستقیماً با `xray api` مدیریتش می‌کند |
| `SSH` | سرور جدا؛ پنل از طریق SSH دستور می‌دهد |
| `دستی` | پنل فقط کانفیگ می‌سازد؛ افزودن کاربر با شماست |
